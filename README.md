# FinTrack – Personal Finance Management

FinTrack is a responsive personal finance management web application built using HTML, CSS and vanilla JavaScript.

The application allows users to manage their income and expenses, view their financial summary, and search, filter and sort transactions.

## Features

- Add income and expense transactions
- Edit existing transactions
- Delete transactions
- Search transactions by title or category
- Filter transactions by income or expense
- Sort transactions by date or amount
- Calculate total income, expenses and balance
- View category-wise expense overview
- Store transaction data using browser localStorage
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Browser localStorage
